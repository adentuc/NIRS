# Директория для скриптов

Эта папка предназначена исключительно для хранения и запуска различных Python-скриптов, связанных с проектом (например, скачивание ГОСТов, обработка данных и т.д.).

## Виртуальное окружение
Внутри этой директории создано отдельное виртуальное окружение с помощью менеджера пакетов `uv`. 
Оно изолирует зависимости скриптов от системного Python.

Чтобы установить новые пакеты для скриптов, перейдите в эту папку и используйте `uv pip install <package>`.
